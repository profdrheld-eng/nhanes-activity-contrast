# Changelog

## 1.0.0 (2026-09-20)

Initial paper-specific release for the NHANES 2003–2006 hip and 2011–2014
wrist activity-contrast analyses. Includes the original analyses, post-hoc
transport and reporting additions, and the exploratory age comparison with
Table S40 export. Original code and repository documentation use the MIT
License; CITATION.cff records software attribution and version.

Scientific interpretation and validation limits are documented in METHODS.md
and VALIDATION.md. Later corrections will receive a new version; this release
must not be silently replaced. Participant-level data and fitted objects are
not included.
